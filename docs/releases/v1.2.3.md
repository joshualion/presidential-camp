# Campaign Manager v1.2.3

This appearance-only maintenance release restores the installation's configured primary brand colour across the administrator interface. The default is `#008751`; changing the saved brand to blue or another colour updates the same primary accents.

- Primary text, page headings, navigation and light sidebar links retain the configured brand instead of falling back to black.
- Add-ons card titles and outlines, primary link actions and primary outline buttons use the same saved colour.
- Dashboard chart and widget links retain their existing white styling, including hover and focus.
- Filled controls keep automatically selected readable foregrounds; no editable foreground-colour setting is introduced.
- Hosting preflight now checks every extension required by the bundled production dependencies, including DOM, SimpleXML, XMLReader, XMLWriter and GD. A CLI-only diagnostic reports missing requirements without revealing credentials or changing the installation.
- Candidate and publication checks rehearse a fresh House of Representatives installation against an empty database, including a registration outage/retry and a completion-report outage.
- No new database migrations or business-functionality changes are included. Reports, AI billing, Finance, donations, Merchandise and paid activation remain unfinished and unavailable.

The release follows the established signed update, explicit installation consent and verified private backup process. Publication requires application, database, backup and browser checks plus rehearsed signed upgrades from the official v1.1.3–v1.2.2 archives. Customer data, settings, credentials, uploads and roles are preserved.
