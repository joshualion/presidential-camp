# Campaign Manager v1.1.3

Corrects release-key configuration so normal installations can check for official updates without locating key files or editing environment settings.

- The installer automatically configures and validates the public key already bundled with Campaign Manager. Existing application keys and deliberate custom trust settings are preserved.
- The corrected updater handles the specific missing legacy template key path using the bundled trusted key. Invalid keys and altered release metadata remain rejected; signature verification is never disabled.
- Includes reviewed upgrade sources and a signed updater bridge for 1.0.8, 1.0.9, 1.1.0, 1.1.1 and 1.1.2. Existing migration history, configuration and uploads are preserved; only reviewed pending migrations may run.
- Retains the Community SMS and time-based automatic-update coverage introduced in 1.1.2. No unattended scheduled-update feature is added in this corrective release.

## Important: already-installed versions

An existing unpatched installation can still show **“The update check could not be completed or verified. Check server connectivity and the trusted release key.”** A published release cannot repair files already installed on your server remotely.

**[Follow the one-time update-check recovery instructions](https://github.com/joshualion/Campaign-Manager/blob/main/docs/update-check-recovery.md).** The guide includes the exact environment correction, cache-clearing command and safe manual upgrade checklist. It is also included in the application ZIP at `docs/update-check-recovery.md`. Do not reinstall over your existing database, generate a new APP_KEY, or disable signature verification.

**Checking for updates and manual downloads are free.** Applying updates through the optional automatic-update service requires active paid coverage for the registered installation and campaign scope. The default purchased coverage period is 12 months and covers eligible releases during that period; there is no automatic renewal. Customers can instead download `campaign-manager.zip` free and follow the manual upgrade instructions.

Download `campaign-manager.zip` for the application. The much smaller `campaign-manager-updater-bootstrap.zip` is an optional signed bridge for supported existing installations, not a complete application or an automatic entitlement to paid updating.

Back up and verify the existing database and files before upgrading. Published 1.1.0, 1.1.1 and 1.1.2 assets remain unchanged.
