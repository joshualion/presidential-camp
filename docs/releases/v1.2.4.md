# Campaign Manager v1.2.4

This release adds a **paid installation-level activation** option for the existing SMS module, improves administration UI contrast, and extends the signed enterprise-entitlement and checkout foundation.

- **SMS module licence:** SMS Messaging appears under Add-ons and is protected by installation-bound signed access when premium enforcement is enabled. Existing direct-provider SMS settings, delegated access, batch sending, delivery reporting, and queued processing remain the same. Campaigns use their own **Termii or BulkSMSNigeria** accounts and pay those providers directly for actual delivery.
- **Portal SMS is separate:** the previously built Portal SMS credit/wallet purchase flow is **not launched or enforced** by this release. No user is required to buy Portal SMS credits in order to use a licensed direct-provider SMS module.
- **Safe rollout:** new SMS enforcement is disabled by default for existing installations, avoiding unintended interruption. Portal checkout also requires an explicit per-feature release flag, active prices for the installation's verified campaign scope, and an operational payment method. Administrators should not enable premium enforcement until installation purchase and entitlement readiness checks pass.
- **Add-on pricing:** Portal pricing and catalogue display now support SMS Messaging; price review is authenticated, tied to the registered installation, and rejects attempts to change the campaign scope. Pending orders are reused to avoid duplicate payment; expired licences can be renewed. Payment reversals remove signed grants.
- **Design:** corrected primary and secondary dashboard card header text/icon contrast while preserving chosen campaign primary colours, and extended add-on card and control contrast regression checks.
- **Security:** updated audited Symfony MIME and mbstring dependencies; premium access is checked at both SMS web routes and direct-provider queued-send boundary. General non-SMS messaging is not affected.
- **Other add-ons:** reporting/AI, finance, and merchandise are still shown as separately licensable catalogue foundations, but cannot be purchased until their operational modules pass their own implementation and acceptance tests.

Signed update validation includes full PHP 8.2/8.3 application suites, MySQL/MariaDB database compatibility, backup checks, browser/interface checks, an independent fresh-install rehearsal, and reviewed signed bootstrap upgrades from official versions 1.1.3 through 1.2.3. Preserve customer data and .env when applying approved upgrades.

**Before turning on licensed SMS:** Portal operator must configure the signed entitlement service, the allowed SMS feature and verified pricing, and confirm `php artisan campaign:enterprise:readiness` succeeds. Existing installations keep SMS entitlement enforcement disabled by default until operator-approved migration.

Release channel: stable. Signed versioned assets are published by the verified Community workflow only; reusing a release tag or replacing its assets is prohibited.

The dashboard stylesheet asset URL is versioned `?v=1.2.4` to prevent stale browser caching after upgrade.

Upgrade matrix validation now includes 1.2.3 -> 1.2.4.
