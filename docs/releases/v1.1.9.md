# Campaign Manager v1.1.9

This release adds consistent password visibility controls and protects saved SMTP credentials in administration screens.

- Use the eye button to show a password and click again to hide it. Each field works independently, with accessible labels and keyboard support.
- Passwords are hidden by default and concealed before submission or page exit. No password values are stored in browser storage.
- Saved SMTP passwords are not returned in HTML or model serialization. Leave the replacement field blank to retain the current credential.
- Existing authentication, validation, installation registration, verified-payment coverage, signed return navigation and explicit update confirmation remain enforced.

No new database migrations are introduced. Existing customer data, uploads, settings and entitlements must be preserved.

## Updating

Open Official Updates and check for the latest release. Automatic updates require verified coverage and explicit installation confirmation; free manual downloads remain available. A return from Portal checkout never authorizes installation by itself.

The publication workflow verifies PHP 8.2/8.3, MySQL/MariaDB backup and recovery, signed archives, and disposable HTTP/bootstrap upgrades from official 1.1.3 through 1.1.8. Rehearsals do not represent a real customer payment or production upgrade.

Older installations with a broken updater can use the included signed recovery bootstrap with the existing recovery instructions in docs/updater-recovery-v1.1.8.md. Installing or opening that bootstrap does not upgrade Core. Never overwrite existing published release assets.
