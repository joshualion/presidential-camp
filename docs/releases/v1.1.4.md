# Campaign Manager v1.1.4

This release improves administrator navigation, SMS composition, dashboard readability and field registration.

- Removes the obsolete Super Admin Community Settings link. Manage community rules in General Settings.
- Shows the pasted phone-number field only when Pasted Phone Numbers is selected.
- Groups Messenger, Email Notifications, SMS and Announcements under Messaging.
- Moves each administrator's SMS Provider into Settings, visible only with SMS access. Other Super Admin settings retain their existing access restrictions.
- Uses white links on colored dashboard widgets and the configured primary theme color on white widgets. Navbar icons follow the primary theme color.
- Replaces the unused navbar grid icon with a working CSRF-protected logout button.
- Adds printable offline registration PDFs alongside member creation. Forms use current profile requirements, configured age/religion/volunteer choices, campaign geography and bank-detail settings. Choose the enrollment level on Add Member. Complete account credentials during office entry.
- Adds Nigeria Democratic Congress (NDC) and its official INEC logo for new and existing installations, preserving existing party details and custom logos.

## Updating from 1.1.3

The signed release declares 1.1.3 as a supported automatic-update source. The update runs only approved pending migrations, including the additive NDC migration. It preserves the database, application key, environment settings and existing uploads. The bundled NDC asset is copied into party image storage only when the default image is absent.

Checking for updates and downloading releases remain free. Applying updates through the automatic-update service requires active coverage for the registered installation. Back up the installation before upgrading and verify login, navigation, SMS configuration and NDC after the update.

Download `campaign-manager.zip` for the application. The optional signed updater bootstrap supports existing 1.0.8 through 1.1.3 installations; it is not a complete application.

This release does not change SMS provider credentials or send messages automatically.
