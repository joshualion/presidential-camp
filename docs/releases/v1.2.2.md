# Campaign Manager v1.2.2

This maintenance release improves readable buttons, navigation and configurable brand colours, and introduces the Super Admin Add-ons catalogue and signed installation entitlement foundation.

- Shared button labels remain readable across common semantic variants, interaction states, custom colours and light/dark modes.
- Only Super Admin sees Add-ons. Enterprise capabilities require explicit grants; geographic administrator rank does not grant Finance or Merchandise access.
- Installation entitlements use a signed, encrypted private cache with bounded offline validity. Existing Community access and update coverage remain independent.
- Dependency fixes address the reviewed npm redirect-header and selector-parser advisories.
- The approved additive permission migration preserves existing customer roles, grants and campaign data, including when the preceding release has cached configuration.

**Available in this release:** the catalogue and licensing foundation. Reports/PDF, AI billing, Finance, donations, Merchandise, checkout and provisioning are not implemented operational modules and are not advertised as available for purchase.

Use the established signed automatic updater or the free manual upgrade procedure. The release package includes production PHP dependencies and built frontend assets, so Composer is not required on the installation server. Never reset an existing database. Automatic updates retain explicit authorization and a verified private backup.

Publication is gated by application tests, MySQL/MariaDB backup tests, dependency audits, archive/signature checks, registration readiness and rehearsed upgrades from the reviewed official 1.1.3–1.2.1 archives. Older updater sources retain their existing prerequisites; only paths actually rehearsed are claimed as validated.
