# Campaign Manager v1.1.1

UI maintenance release. Preserves installation registration, update signature checks, application permissions and campaign data.

- Official Updates checks automatically when the last successful check is more than 15 minutes old. One primary action downloads and verifies an available update for review.
- Registration/contact preferences have moved to Settings → Installation registration.
- A prepared update is clearly distinguished from the installed version. This release does not apply staged updates automatically.
- Server access confirmation now follows the installer branding, with clear instructions, accessible validation and mobile layouts.
- Installer choices and registration checkboxes adapt to narrow screens.

## Installing this update

Back up the application and database. Follow the existing manual upgrade procedure, preserve `.env`, uploads and installation state, and run only the required safe migrations. Update preparation alone does not replace application files or run migrations.

The portal UI and logo fixes are deployed from the separate private portal repository. They are not included in the Core archive.

## Publication

Publish only after owner-authorized CI validation and merge. Use the established signing identity and the three official assets: `campaign-manager.zip`, `campaign-manager.zip.sha256`, and `release-manifest.json`. Preserve the existing v1.1.0 release.
