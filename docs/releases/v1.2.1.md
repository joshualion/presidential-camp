# Campaign Manager v1.2.1

Roles and permissions now use one integrated workflow under the existing **Roles & Permission** menu. **Manage Roles** creates and edits reusable roles with the full independent action-permission catalog. Existing roles use the same records and IDs. The role-permission list and edit links open the same editor; default permissions are shown for existing roles before saving. User role assignments, individual permissions and defaults are available within the same module.

Super Admin retains full system control. Other users receive the permissions assigned to them while their administrative routes, geographical scope and licensed features continue to apply.

Dashboard is first in the navigation. **Incident Evidence Settings** is under **Elections**, alongside Manage Elections, and remains restricted to Super Admin for both viewing and saving. **Official Updates** follows Roles & Permission and precedes Profile. Verified available updates display a red notification throughout Super Admin pages. All controls use the existing brand styling and dark-mode conventions. Technical compatibility banners and duplicate top-level links have been removed.

There are no new database migrations in this correction. Existing user-role assignments and historical election/evidence records are preserved. Upgrades from 1.2.0 require no additional migration; earlier sources apply only the already reviewed additive migrations. Signed package rehearsals cover official 1.1.3 through 1.2.0 archives.

Customers initiate their own updates through Official Updates with the existing signature, entitlement, consent, backup and recovery checks. The immutable v1.2.0 release remains available unchanged.
