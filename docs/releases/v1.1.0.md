# Campaign Manager Community Edition v1.1.0

Candidate release notes. Publication requires all security, service and signing gates to pass.

- New installations accept licence/privacy terms and obtain a required, free installation receipt from the official portal.
- Registration sends only administrative contact email, configured domain, installation UUID, software version, status and terms acceptance, using a dedicated registration credential over HTTPS. It does not send campaign records, voters, political activity, operator phone numbers, passwords or application authentication secrets.
- Marketing preferences remain separately optional. Free use creates no payment obligation; professional installation, hosting, maintenance, training and assisted upgrades are optional services.
- Registration retries retain an encrypted installation identity and preserve existing configuration and database records. Established installations remain operational during the transition and temporary portal failure.
- Super Administrators can resend contact confirmation and request an email-confirmed domain migration.
- Includes the existing stabilization work: installer ownership proof, controller/route repairs, upload validation, privacy protections, dependency refresh and verified official update staging.

Automatic update application and rollback are not included. Use the documented manual maintenance process: verify the signed release, back up the database, environment, storage and uploads, preserve the application key and installation lock, and apply compatible migrations. Never rerun the new-install wizard over populated deployments or reset databases.

Only use official `campaign-manager.zip` assets. Verify the checksum and signed manifest against the established public key. Earlier releases remain unchanged.
