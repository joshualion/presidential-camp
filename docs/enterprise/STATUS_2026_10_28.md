## Main-branch policy

The maintenance workflow deletes only exact heads of merged same-repository PRs or branches fully contained in main. It preserves the default branch, protected branches, open-PR work, changed heads and unmerged commits; a fresh head/open-PR check precedes deletion. Manual runs default to dry-run. PR closure without merge never authorizes deletion.
